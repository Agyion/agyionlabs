## Demonstrated issues and fixes

1. **Release verification could hide unreviewed JavaScript.** `verify-production-release.mjs` stripped a broad wildcard Cloudflare bootstrap if it contained the expected URL. A saved bootstrap with `window.__unreviewedCode=true;` inserted into its body was still accepted by that regex. The replacement `release-integrity.mjs` pins the observed entire bootstrap and permits only the 16-hex ray value and canonical Base64 10-digit timestamp to vary. Extra or modified instructions, changed URLs, duplicate bootstraps, analytics scripts and noncanonical challenge data fail. Raw body SHA is recorded before comparison; an accepted edge bootstrap retains its raw text and SHA. This is evidence normalization, not permission for that script to execute; browser CSP/error gates remain unchanged.

2. **Release CSP check missed unsafe permissions.** Its one literal substring missed reordered `unsafe-inline` and all `unsafe-eval` permissions. The pure replacement parses individual directives/tokens, requires an explicit script-src, rejects duplicate/malformed policies, and rejects unsafe-inline/unsafe-eval/wasm-unsafe-eval in script and default directives regardless of order/case. Frame ancestors must be exactly none. Existing inline styles remain allowed; no analytics source was added.

3. **Two visual harnesses expected the obsolete Pod secret lifecycle.** `verify-holographic-ui.mjs` and `verify-workspace-ui.mjs` required 32 hex characters; the holographic harness expected secrets to survive inactive tabs. Assertions now require V3 64-hex credentials, preserve only nonsecret amount/time drafts on close/switch, retain secrets through in-place help, and reset saved-backup acknowledgement for a new secret. The explicit mock-only Pod flow also verifies save-before-funding; the parent corrected its claim-field selector to exact matching. No runtime or handler was changed in this task.
